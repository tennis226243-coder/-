# 間取り3D

間取り図（フロアプランの画像）から 3D 図面を作成する Web アプリです。
ブラウザだけで動作し、画像やデータが外部に送信されることはありません。

## できること

- **画像の読み込み**：PNG / JPG などの間取り図をファイル選択・ドラッグ＆ドロップ・貼り付け (Ctrl+V) で読み込み
- **縮尺合わせ**：寸法のわかる 2 点をクリックして実寸 (m) を入力
- **壁の自動検出**：画像の太い黒線を壁として検出し、文字・寸法線・ドアの円弧などの細い線は無視
  - 図面中の長い線の太さから壁厚を推定し、細い壁の図面にも対応
  - 壁の隙間を自動でドア・窓に変換（隙間に窓記号の平行線があれば窓、なければドア）
  - 検出の設定（明るさ・最小の壁厚）を変えるとその場で検出し直す
  - **色から部屋を推定**：不動産の間取り図の塗り色（畳の緑・水回りの水色・洋室のベージュ）から部屋の範囲を見つけ、和室は畳、浴室・洗面・トイレはタイルにする。名前は広さと形から推定（LDK・洋室・廊下・浴室・洗面・トイレ）
- **手動編集**：壁・ドア・窓・部屋（床）の作図、ドラッグでの移動・伸縮、数値での寸法指定、元に戻す / やり直す
- **3D 表示**：天井高・壁厚・壁の色・透明度を指定してリアルタイムに 3D 化。ドア・窓（ガラス・サッシ）・巾木付き。床はフローリング（3 色）・タイル・間取り図から選択。照り返しのある照明でモデルルーム風に表示
- **部屋の床材**：部屋ごとに畳・浴室タイル・タイル・フローリング（3 色）を選択。名前に「和室」「浴室」などがあれば自動で設定
- **人の配置**：大人（立ち・座り）と子どもを置いて、広さや通路幅の目安にできる（服の色・身長も変更可）
- **家具・設備の配置**：ソファ・ベッド・ダイニングセット・キッチンなどの家具に加え、浴槽・トイレ・洗面台・押入れ（ふすま）・座卓・座布団・下駄箱など 32 種類を実寸で置き、移動・回転・サイズ変更。3D にも表示され、案ごとに別の配置を持てます
- **リノベーション案の比較**：案を複製して壁の撤去・追加などを行い、2 つの案の 3D を並べて比較（撤去・新設した壁を色分け、視点は連動、壁・開口部の数や面積の差を表示）
- **ウォークスルー**：WASD キーとマウスで室内を歩いて確認
- **画像から 3D まで自動**：画像を読み込むと、すぐに壁・ドア・窓を検出して 3D に変換（縮尺が未設定なら外形が約 65㎡ になる仮の縮尺を使用）
- **3D データの保存**：GLB（多くの 3D ソフト・ビューアー）、USDZ（iPhone / iPad で AR 表示。iPhone ではそのまま AR で開く）、OBJ（形状のみ）。ほかにプロジェクト (.json)、画像 (.png)
- 作業内容はブラウザに自動保存され、再訪問時に復元されます

## 使い方

1. 「画像を選択」で間取り図を読み込む（まずは「サンプル間取りで試す」でも OK）
2. 「縮尺」ツール (M) で寸法線の両端をクリックし、実際の長さを入力
3. 「壁を自動検出」を押す。うまく検出できない場合は「検出の詳細設定」で明るさのしきい値や最小の壁厚を調整
4. 必要に応じて各ツールで修正し、右側の 3D ビューで確認・書き出し

### 操作

| ツール | キー | 操作 |
| --- | --- | --- |
| 選択 | V | クリックで選択、ドラッグで移動、端点ドラッグで伸縮、Delete で削除 |
| 壁 | W | 指（マウス）でなぞると壁を 1 本作図。クリック / タップで連続作図も可能（水平・垂直に自動スナップ、Shift で自由角度）。最後の点をもう一度押す / 右クリック / Esc で終了。スマホでの画面移動は 2 本指 |
| ドア / 窓 | D / N | 壁の上をクリックして配置。選択して幅・高さ・床からの高さを変更 |
| 部屋 | R | 頂点をクリックし、始点クリック / Enter で確定。面積（㎡・畳）を表示 |
| 家具 | F | 家具の一覧から選ぶと図面の中央に置かれる。ドラッグで移動、選択して回転（90° ずつ / 角度指定）・サイズ・色を変更、複製 |
| 縮尺 | M | 長さのわかる 2 点をクリック |
| 移動 | H | ドラッグで画面移動（Space + ドラッグ、ホイールでズームも可） |

元に戻す：Ctrl+Z ／ やり直す：Ctrl+Shift+Z または Ctrl+Y

## 開発

```bash
npm install
npm run dev      # 開発サーバー (http://localhost:5173)
npm test         # 単体テスト（壁検出・幾何計算）
npm run build    # dist/ に静的ファイルを出力（GitHub Pages などにそのまま配置可能）
```

### GitHub Pages で公開

`main` ブランチに push すると、GitHub Actions（`.github/workflows/deploy.yml`）がテスト・ビルドを行い GitHub Pages に公開します。
初回のみ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定してください。
公開 URL は `https://<ユーザー名>.github.io/<リポジトリ名>/` です（Actions タブからの手動実行も可能）。

### 構成

| ファイル | 役割 |
| --- | --- |
| `src/model.js` | データモデル・幾何計算（壁を開口部で分割する処理など） |
| `src/autodetect.js` | 画像からの壁検出（二値化 → モルフォロジー処理 → 矩形抽出 → 端点接続）と開口部判定 |
| `src/editor.js` | Canvas による 2D エディタ |
| `src/viewer3d.js` | three.js による 3D 生成・表示・GLB 書き出し |
| `src/textures.js` | 床材テクスチャ（フローリング・タイル・畳・浴室タイル）の生成 |
| `src/rooms.js` | 部屋の床材と、塗り色からの部屋の推定 |
| `src/furniture.js` / `src/furniture3d.js` | 家具カタログ・当たり判定 / 家具の 3D モデル |
| `src/variants.js` | リノベーション案の保存・切り替え・差分・集計 |
| `src/sample.js` | デモ用の 2LDK 間取り図の生成 |
| `src/main.js` | UI の結線・履歴・保存 |

### 自動検出のしくみと制限

壁は「一定以上の太さで塗りつぶされた水平・垂直の線」として検出します。
黒く塗られた壁の図面に向いており、斜めの壁、白抜き（二重線）の壁、写真のような図面はうまく検出できないことがあります。
その場合は壁ツールで画像をなぞって作図してください。
