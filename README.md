# 間取り3D

間取り図（フロアプランの画像）から 3D 図面を作成する Web アプリです。
ブラウザだけで動作し、画像やデータが外部に送信されることはありません。

## できること

- **画像の読み込み**：PNG / JPG などの間取り図をファイル選択・ドラッグ＆ドロップ・貼り付け (Ctrl+V) で読み込み
- **縮尺合わせ**：寸法のわかる 2 点をクリックして実寸 (m) を入力
- **壁の自動検出**：画像の太い黒線を壁として検出し、文字・寸法線・ドアの円弧などの細い線は無視
  - 壁の隙間を自動でドア・窓に変換（隙間に窓記号の平行線があれば窓、なければドア）
- **手動編集**：壁・ドア・窓・部屋（床）の作図、ドラッグでの移動・伸縮、数値での寸法指定、元に戻す / やり直す
- **3D 表示**：天井高・壁厚・壁の色・透明度を指定してリアルタイムに 3D 化。ドア・窓（ガラス・サッシ）付き
- **ウォークスルー**：WASD キーとマウスで室内を歩いて確認
- **保存・書き出し**：プロジェクト (.json)、3D モデル (.glb：Blender や 3D ビューアーで開けます)、画像 (.png)
- 作業内容はブラウザに自動保存され、再訪問時に復元されます

## 使い方

1. 「画像を選択」で間取り図を読み込む（まずは「サンプル間取りで試す」でも OK）
2. 「縮尺」ツール (M) で寸法線の両端をクリックし、実際の長さを入力
3. 「壁を自動検出」を押す。うまく検出できない場合は「検出の詳細設定」で明るさのしきい値や最小の壁厚を調整
4. 必要に応じて各ツールで修正し、右側の 3D ビューで確認・書き出し

### 操作

| ツール | キー | 操作 |
| --- | --- | --- |
| 選択 | V | クリックで選択、ドラッグで移動、端点ドラッグで伸縮、Delete で削除 |
| 壁 | W | クリックで連続作図（水平・垂直に自動スナップ、Shift で自由角度）、右クリック / ダブルクリック / Esc で終了 |
| ドア / 窓 | D / N | 壁の上をクリックして配置。選択して幅・高さ・床からの高さを変更 |
| 部屋 | R | 頂点をクリックし、始点クリック / Enter で確定。面積（㎡・畳）を表示 |
| 縮尺 | M | 長さのわかる 2 点をクリック |
| 移動 | H | ドラッグで画面移動（Space + ドラッグ、ホイールでズームも可） |

元に戻す：Ctrl+Z ／ やり直す：Ctrl+Shift+Z または Ctrl+Y

## 開発

```bash
npm install
npm run dev      # 開発サーバー (http://localhost:5173)
npm test         # 単体テスト（壁検出・幾何計算）
npm run build    # dist/ に静的ファイルを出力（GitHub Pages などにそのまま配置可能）
```

### 構成

| ファイル | 役割 |
| --- | --- |
| `src/model.js` | データモデル・幾何計算（壁を開口部で分割する処理など） |
| `src/autodetect.js` | 画像からの壁検出（二値化 → モルフォロジー処理 → 矩形抽出 → 端点接続）と開口部判定 |
| `src/editor.js` | Canvas による 2D エディタ |
| `src/viewer3d.js` | three.js による 3D 生成・表示・GLB 書き出し |
| `src/sample.js` | デモ用の 2LDK 間取り図の生成 |
| `src/main.js` | UI の結線・履歴・保存 |

### 自動検出のしくみと制限

壁は「一定以上の太さで塗りつぶされた水平・垂直の線」として検出します。
黒く塗られた壁の図面に向いており、斜めの壁、白抜き（二重線）の壁、写真のような図面はうまく検出できないことがあります。
その場合は壁ツールで画像をなぞって作図してください。
