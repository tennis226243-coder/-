# ハジキ・ブレイブ

引っ張って弾く「ひっぱりアクションRPG」ジャンルのオリジナルゲームです。
HTML5 Canvas と素の JavaScript だけで動きます（ビルド不要・依存なし）。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（スマホのタッチ操作にも対応）。

```sh
# ローカルサーバーで動かす場合
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

- **フィールドを引っ張って離す**と、手番のキャラが逆方向に飛び出します。引っ張る距離が長いほど速くなります。
- キャラは壁や敵に当たって跳ね返り（**反射**タイプ）、または敵をすり抜けて（**貫通**タイプ）ダメージを与えます。
- 移動中に**味方に触れるとリンクスキル**が発動します。
  - ヒノコ：バーストリンク（周囲の敵に爆発ダメージ）
  - ミナモ：ヒールリンク（HP回復）
  - ソヨギ：ホーミングリンク（追尾弾×4）
  - ルクス：クロスレーザー（十字方向の敵にダメージ）
- 下のカードに「TAPでスキル!」と出たら、タップで**必殺スキル**を使えます。
- 敵の左上の数字は攻撃までのターン数。0 になるとチームHPにダメージを受けます。
- ボスの光る**弱点**に当てると 3 倍ダメージ。弱点はターンごとに移動します。
- 属性相性：炎→風→水→炎、光⇔闇（有利で 1.5 倍、不利で 0.66 倍）

全 3 ステージ（各 3 ウェーブ、最後はボス）。クリア状況はブラウザに保存されます。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | キャンバスを置いたエントリーページ |
| `game.js` | ゲーム本体（物理・戦闘・描画・入力・ステージデータ） |

### `game.js` の主な拡張ポイント

- `ROSTER` … プレイヤーキャラ（属性・反射/貫通・攻撃力・リンクスキル・必殺スキル）
- `STAGES` … ステージとウェーブごとの敵配置（`E(名前, 属性, HP, 攻撃力, 攻撃ターン, x, y, 半径, {boss})`）
- `triggerLink` / `useSkill` … リンクスキル・必殺スキルの効果
- `FRICTION` / `LAUNCH_SPEED` … 弾きの手触り
